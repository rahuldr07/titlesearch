## 6. The visual direction (the current reference)

Chosen hybrid, owner's words: **"A theme, B simplicity, C font, sidebar from A."**

- **Palette / depth / sidebar — A "Archival."** Warm stacked paper tones as the
  depth mechanism, low soft shadows instead of hairline borders, sealing-wax
  accent `#8A3222`.
- **Density and plainness — B "Precision Instrument."** Row padding 11×18
  (queue), 9×15 (decision), 8×16 (matrix). Where A is decorative and B is plain,
  **prefer B.**
- **Typography — C "Editorial."** Fraunces display (h1, order numbers, the
  italic decision question), Switzer body/UI, Geist Mono for every value and
  cite with `tnum`, Courier Prime inside the facsimile only.

Reference artefacts (scratchpad — **copy somewhere durable if they matter**):
`scratchpad/directions/{a-archival,b-instrument,c-editorial,hybrid}.html` and
their `-full.png` renders. The approved one is `hybrid.html`.

Fraunces deliberately stays OUT of dense tables — its figures are not tabular and
it is a display voice, not a text economy. The clients matrix proves the system.

## 7. Open items

**Known and unfixed**
1. Gallery's closed-gap chips (`CLOSED · ADDED` / `CLOSED · AMENDED` /
   `NOTE ONLY`) collapse to one rectangle in greyscale. Not NA states, so no rule
   forbids it — but the gallery is where that distinction should hold.
2. Signin wordmark is `TITLEPIPE` in tracked caps; the mockup has `Title` +
   Fraunces-italic `Pipe`.
3. `/api/orders/:id/fields` in `packages/mocks/src/handlers.ts` is **order-blind**
   — returns `ord_demo_1`'s 21 fields for any id. Visible now that `/questions`
   resolves to `ord_demo_4`. Fixing it changes what `navigation.spec:91` sees.
4. `entities/signoff/*` is stories-only: `/questions` serves an unsigned order so
   the readonly branch is unreachable.
5. `review.spec` no longer asserts the strip communicates signature state (it
   moved from a client-composed string to the server's stamp). Worth an assertion.
