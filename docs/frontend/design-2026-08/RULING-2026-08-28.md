# Owner ruling — 2026-08-28

**Build the reference app as drawn, and extend the contract so the data is real.**

Recorded because `CONFLICT-all-orders.md` §7 requires a ruling to be written down rather
than inferred, and because an earlier agent twice marked invariants superseded on a ruling
nobody had made.

## What is now authorised

1. **`packages/contract` is no longer frozen for this work.** New endpoints and new members
   may be added where a design screen needs them. Existing shapes keep their meaning;
   nothing already ratified changes semantics.
2. **`packages/mocks` gains handlers** for everything added, so every screen runs on real
   wire data rather than a gap card.
3. **Every screen in `reference-app.html` gets built**, including the six with no surface:
   All Orders, Release Compiler, Templates Architect, the QC role view, the typist capture
   seat, and the jurisdiction view.
4. **A browse surface is legitimate.** `GET /api/orders` with search, filter and pagination
   may exist. This is `CONFLICT-all-orders.md` Option C.

## What this does NOT overturn

The anti-patterns stay anti-patterns — they are product decisions, not missing surface, and
the design drawing one is not an argument for it:

- No throughput counters, no per-person rates, no auto-tuning, no approve-all.
- No probe visibility; `/api/metrics` stays off the screens that must not show it.
- Provenance on every emitted value; the four-state NA taxonomy never collapses.
- Refusals stay server-authored and surfaced verbatim.
- The server still owns state machines and thresholds.

## Invariants affected

22 (queue browsing) and 23 (pace indicators) are the two the browse table touches. They are
**narrowed, not deleted**: the queue's own hand-over stays one server-chosen order with no
cherry-picking, and All Orders is a separate ops surface. A `Due` column may exist because
the server owns the date; a client-computed countdown still may not.

## Consequences for the open conflicts

- `CONFLICT-all-orders.md` — resolved, Option C.
- `CONFLICT-overview-stats.md` — resolved by Option A: `LifecycleResponse` gains the members
  the four named cards need.
- `CONFLICT-ink-faint-contrast.md` — still open. A token value is a design decision and this
  ruling is about surface, not palette.
- `CONFLICT-caps-in-strings.md` — still open. It needs spec edits, which this does not cover.
